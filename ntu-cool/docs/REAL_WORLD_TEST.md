# 真實環境驗證記錄

第一次對真實 NTU COOL 執行時，請**照順序**做，不要一開始就整學期同步。
每一步把觀察到的行為填進來。**貼上任何內容前，請把權杖、cookie、學號與簽章網址遮掉。**

## 前置

```bash
cd ntu-cool
python3 -m ntucool login          # 或手動設定權杖
python3 -m ntucool whoami         # 確認身分
```

| 步驟 | 指令 | 預期 | 實際結果 | 日期 |
|---|---|---|---|---|
| 1. 權杖有效 | `whoami` | 顯示你的名字 | | |
| 2. 課程清單 | `courses` | 列出這學期的課 | | |
| 3. 單一課程預演 | `sync -c <課號> --dry-run` | 列出會下載什麼，不寫檔 | | |
| 4. 單一小檔 | `sync -c <課號> --ext pdf --max-file-mb 1` | 下載成功 | | |
| 5. 檔名與內容 | 開啟下載的檔案 | 檔名正確、內容可讀 | | |
| 6. 中文／重複檔名 | 檢查輸出資料夾 | 中文保留、重複檔名有編號 | | |
| 7. 整門課 | `sync -c <課號>` | 全部完成 | | |
| 8. 增量 | 再跑一次同樣指令 | 新增／更新 0 個 | | |
| 9. 權杖過期 | 在 NTU COOL 撤銷權杖後再跑 | 明確的權杖錯誤，不是 stack trace | | |
| 10. 中斷 | 下載途中 Ctrl+C，再跑一次 | 沒有殘留 `.part`，接續補完 | | |
| 11. 分頁 | 課程或檔案數 > 100 的情況 | 全部抓到，不漏 | | |
| 12. 限流 | 觀察 `-v` 輸出 | 有退避重試，不整批失敗 | | |
| 13. 整學期 | `sync` | 完成；未取得項目有列出原因 | | |
