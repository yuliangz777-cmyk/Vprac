# 已知限制與驗證邊界

這份文件記錄**做不到的事**、**刻意不做的事**，以及**還沒在真實 NTU COOL 上驗證過的事**。
每次真的跑過之後請更新它——沒有被真實資料驗證過的東西，不要當成已完成。

## 一、技術上做不到

| 項目 | 原因 |
|---|---|
| 純前端網頁直接呼叫 NTU COOL | Canvas 不對外部網域送 CORS 標頭。因此本專案採「瀏覽器 ↔ 本機伺服器 ↔ NTU COOL」，權杖留在本機 |
| 用學校帳號密碼登入 | NTU 走 SSO，沒有帳密登入的 API |
| 學期成績、課表、畢業學分、今日課程 | 這些在 myNTU 校務系統，不是 Canvas；沒有 API |
| 「Wi-Fi 才下載」開關 | 網頁量不到連線類型（Network Information API 在 Safari 不支援）。**不提供**這個開關，而不是提供一個騙人的開關 |
| 區網 IP（`http://192.168.x.x`）的離線功能 | Service Worker 需要安全來源；`127.0.0.1` 算，區網 http 不算 |

## 二、刻意不做

- **不**冒用官方 App 的 OAuth client / developer key
- **不**做看起來像 NTU SSO 的帳密輸入頁
- **不**繞過 MFA / CAPTCHA / SSO
- **不**把權杖、cookie、密碼放進前端、fixtures、日誌或版本庫

## 三、必須在真實 NTU COOL 上驗證（目前只對假站台測過）

- [ ] 權杖／登入路徑（含 `browser_login.py` 在真實 SSO 上的流程）
- [ ] 課程權限差異（關閉檔案分頁、隱藏單元、未發布內容）
- [ ] 分頁（`Link` 標頭）在大量課程／檔案時的行為
- [ ] 限流：429 與 403 Rate Limit 的實際觸發點
- [ ] 檔案下載網址的轉址與簽章有效期
- [ ] Unicode 與重複檔名
- [ ] 大檔（數百 MB 以上）
- [ ] 行事曆事件的實際欄位
- [ ] 作業的可見性與 `submission` 欄位
- [ ] 權杖過期時的行為

## 四、平台行為（只能在你的裝置上驗證）

- a-Shell：`curl` / `tar` / `python3` 是否可用、能否綁連接埠、Safari 開 `127.0.0.1`
- 捷徑 App 的 a-Shell 動作名稱與 iOS 自動化是否準時觸發
- iOS 把背景的 a-Shell 凍結之後，本機伺服器的存活狀況
- PWA 安裝與離線行為（在電腦的 `127.0.0.1` 上已驗證）

## 規則

**不確定的端點或行為 = 記錄下來 + 用假站台測 + 寫進測試計畫。**
不要憑空發明端點，也不要只靠假站台的測試就宣稱整合完成。
